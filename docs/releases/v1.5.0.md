## RecallForge v1.5.0

A redesigned interface and a much sturdier AI import path.

### Highlights

- **New "index card" UI:** Warm paper background, cobalt / vermilion / mustard / fern color blocks, 2px ink outlines, hard offset shadows that press down on click, and a heavy condensed Bricolage display face. Light and dark themes.
  - Color-blocked deck tiles and home rows with a due badge and mastery bar; tile color follows each deck's chosen color.
  - Deck page hero with Due / Learning / Mastered tiles and a full-width review button.
  - Study card drawn as a stack; grade buttons lead with big 1–4 keys.
- **OpenRouter support:** Provider resolved in one place (`AI_PROVIDER`, `OPENROUTER_MODEL`, `GEMINI_MODEL`, `AI_MODEL`), model slugs validated before the daily quota is used, attribution headers sent, OpenRouter's in-body errors and 401/402/404 cases handled, fenced or prose-wrapped JSON parsed, and the model actually routed to is reported.
- **AI settings from `process.env`:** Fixes the provider showing "NOT CONFIGURED" on hosts that expose dashboard variables through `process.env` instead of Worker bindings.
- **More forgiving AI flashcard generation:** Individual bad cards are skipped (with a skipped count shown) instead of rejecting the whole set; multi-part answers are merged; source-excerpt matching ignores case, quotes, dashes and trailing punctuation; extra cards are trimmed to the requested count.
- **App screenshots:** Desktop light/dark and mobile, plus before/after shots in `screenshots/`.
